
#Budget Tracker

## About
An interactive beginner-level Python project that
allows users to manage their income and expenses.

## Technologies
- Python
- Pandas
- NumPy
- Google Colab

## Features
- View existing transactions.
- Add new income and expenses.
- Automatically update CSV dataset.
- Calculate total income.
- Calculate total expenses.
- Calculate remaining balance.
- View expenses by category.
- Find highest expense.
- Calculate average expense.

## Project Files
- Budget_Tracker.ipynb
- transactions.csv
- README.md

## Installation
pip install pandas numpy

## How to Run
1. Open Google Colab.
2. Upload transactions.csv.
3. Open Budget_Tracker.ipynb.
4. Run the code.
5. Select an option from the menu.
